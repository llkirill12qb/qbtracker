Restore

Production restore is intentionally not a web button yet. The safer path is to restore to a test database first, verify, then replace production only when needed. 

cd /srv/qbtracker
systemctl stop qbtracker.service
source .env
gunzip -c /srv/backups/qbtracker/qbtracker_db_TIMESTAMP.sql.gz | psql "$DATABASE_URL"
systemctl start qbtracker.service

Safety Checks
